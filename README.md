# 🎓 Student Task Manager

Simple web application untuk membantu mahasiswa mengelola tugas kuliah dan deadline dengan lebih rapi.

## ✨ Features

- ➕ Tambah tugas
- 📋 Melihat daftar tugas
- 🔄 Mengubah status tugas
- 🗑️ Menghapus tugas
- 📅 Menentukan deadline tugas
- 📱 Tampilan responsive

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- Git & GitHub
